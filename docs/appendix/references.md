# References

This page provides key references related to studies and reports that have used the **GTFS4EV** model.

- *Energy, environment, and economy implications of electrifying minibus taxis in African cities* (Scientific Reports). Dumoulin, J., Pena-Bello, A., Jeannin, N. et al. Sci Rep 16, 10661, 2026. Open access paper available at: [https://doi.org/10.1038/s41598-026-45790-w](https://doi.org/10.1038/s41598-026-45790-w).

- *GTFS4EV: A Python framework for electric bus planning using GTFS data* (submitted to JOSS - Under review). Available at: [https://joss.theoj.org/papers/166f4e1d6f3e2221540f04b1c4cae669](https://joss.theoj.org/papers/166f4e1d6f3e2221540f04b1c4cae669).

- *Strategic Scenario‑Based Modeling for Optimal Electric Bus Charging Station Deployment in Addis Ababa* (Master thesis, Addis Ababa University). Melkye Yifru, 2025. This work evaluates electrification strategies and charging infrastructure for e‑bus deployment in Addis Ababa, Ethiopia. Full thesis available at [Addis Ababa University repository](https://etd.aau.edu.et/items/107b4ad1-1026-4e24-9df8-f57f66f5afa3).

- *Supporting the transition to electric minibuses in Lusaka, Zambia: A preliminary analysis using the GTFS4EV model* (Working paper). This work illustrates the application of GTFS4EV using openly avaible GTFS data for Lusaka. Access it [here](../cases/GTFS4EV_Lusaka_report_open.pdf).
