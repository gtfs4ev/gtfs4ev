This folder contains an example datasets used to illustrate the usage of **GTFS4EV** in the provided API and CLI configurations. Examples are used **for demonstration purposes only**.

## Sample GTFS data

The example GTFS feed is derived from the **Digital Matatu Project** for Nairobi, Kenya. The `sample_gtfs` folder contains a **subset of the Nairobi GTFS feed**, reduced to **2 routes** for demonstration purposes. This allows quick execution of the examples.

- Source: Digital Transport For Africa Gitlab (downloaded 01.09.2024)
- Description: GTFS data describing public minibus transport in Nairobi collected through the Digital Matatu Project
- Link: https://gitlab.com/digitaltransport/data/africa/nairobi

## Population raster data

The population raster dataset is based on the **Global Human Settlement Population (GHS-POP)** data for the year 2020, cropped to the Nairobi region.

- Source: European Commission, Joint Research Centre (JRC)  
- Dataset: GHS-POP R2023A  
- Reference year: 2020  
- Website: https://human-settlement.emergency.copernicus.eu/download.php?ds=pop
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)

The raster is used to demonstrate ex-post analyses related to population exposure to air pollution.
